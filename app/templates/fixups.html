🔧 Fixups — manual text fixes when the automatic harvest misses something

When do I use this? The engine reproduces decks automatically, but a few text bits can slip through — for example a client name in an unusual spot, or wording that changes with an option (e.g. “new audit client” becomes “expansion of services”). If Diff shows a text mismatch, add a small rule here, then rebuild and diff again.

Rules are saved with the asset and are re-applied every time you Reconstruct. They survive rebuilding the library, so your manual work is never lost.

1. Fill in a value

Use when a client name or date wasn't replaced somewhere. “Wherever the deck says this text, put the value from this field.”

Example: Find “Example Corporation” → Full client name. Now every deck gets the right client there.

2. Swap text for a condition

Use when wording changes with an option. “When this field is this value, replace A with B.”

Example: When “New client or Expansion” is “Expansion of Services”, replace “new audit client” with “expansion of services”.
